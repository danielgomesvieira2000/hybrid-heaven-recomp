# Hybrid Heaven: Recompiled 0.1.0

**This is a very early build and it is still very untested.** Only the start of the game has been
played: boot, the menus, New Game, the opening cinematic and the first rooms. Everything after that
needs a lot of testing now. Please report crashes, broken scenes, and graphics, audio, save or
controller problems.

* First release: a native Windows and Linux port of Hybrid Heaven (USA)
* Widescreen at your window's shape, with the game's overscan border removed
* HUD elements anchored to the screen edges in widescreen (the radar so far)
* Launcher with graphics, sound and controls settings, remapping and a mods tab
* Keyboard and controllers for 1–2 players; controllers are assigned as they are plugged in
* Controller Pak saves, and the Rumble Pak on the same controller without swapping
* F1 debug menu with a live HUD editor

You need your own dump of **Hybrid Heaven (USA)**. Windows: unzip and run
`hybrid-heaven-recomp.exe`. Linux: extract and run `./hybrid-heaven-recomp.sh`.
