# Hybrid Heaven: Recompiled 0.2.0

**Still an early build, and still untested.** Only the start of the game has been played so far: the
first rooms and the first battles. Please report crashes, broken scenes, and graphics, audio, save
or controller problems.

* Fixed: the game crashed during the cutscene where you meet the first enemy. Battles now load and
  play.

Known issues:
* No high frame rate yet
* The high-resolution mode from the main menu has not been tested

Not tested:
* The Linux build was only started under WSL, not played

You need your own dump of **Hybrid Heaven (USA)**. Windows: unzip and run
`hybrid-heaven-recomp.exe`. Linux: extract and run `./hybrid-heaven-recomp.sh`.
